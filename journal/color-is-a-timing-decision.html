Color is a timing decision

A printer light is not the color. It is a promise that someone else can find the color again.

A printer light is a number a lab can repeat. On a traditional printer the scale often runs from 1 to 50. You start at 25, not because 25 is a law of light, but because the lab agreed to treat it as the center. Move red, and the print changes in a way the next person can follow, if you both trust the same scale.

Software is full of the same kind of number. A timing offset. A color transform. A default in a design token. The number is not the color. The number is a promise that the color can be found again tomorrow, by someone who was not in the room.

I am a software engineer moving toward the rooms where pictures get finished: color, archives, delivery. Those rooms already run on records. A show looks the way it looks because somebody wrote the lights down.

The center is the decision

The bench on the front of this site is a teaching model of that record. Three channels, a center at 25, a picture that tints when the numbers move, and a reset that returns you to the promise you started with. It is not a calibrated analyzer, and the page says so. A tool that pretends to be more precise than it is will train people to distrust the next number they see.

You cannot describe a difference if you cannot describe the start.

That distrust is expensive in a lab. If the lights on the can do not match the lights in the notebook, the argument is no longer about the picture. It is about which record to believe. Good software, like a good timer, keeps one record and makes the center obvious.

I care about the center more than the range. Ranges are easy to add. A center is a decision: this is normal, this is the place we return to, this is what we will call unchanged. Interfaces that hide their default make every later change harder to read.

Cinema already knows this. A one-light dailies pass is a center. A hero grade is a departure from it, written so it can be repeated on the next reel. The paperwork is the craft. The picture is what the paperwork protects.

What I want to build sits in that space. Tools for people who look at images for a living, where a number on screen corresponds to a number on a report, and where “back to the start” is always available. The bench is a small proof that I will label a model as a model.
